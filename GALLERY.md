# Runtime gallery

These are unedited 1280×800 screenshots from the collection's 2026-08-23 release verification in a disposable x86_64 Omarchy Quattro guest. Every child was copied into the native theme directory, applied through `omarchy-theme-set`, checked for valid merged runtime TOML and its intended accent, then photographed with a real Foot terminal, Omarchy menu, and Omarchy notification on screen.
